# Pulsegrid cloud

This folder is the deployable Node.js application. The latest Hostinger upload is the ZIP in `versions/` whose name starts with `pulsegrid-cloud-`.

The ZIP contains `server.js`, the Node package files, and `public/`. It intentionally excludes `.env`, `node_modules`, legacy copies, and previous ZIPs. Configure secrets in the Hostinger environment rather than committing them.

Each firmware device authenticates telemetry, command polling/ACKs, and OTA with the unique 32-character hexadecimal `DEVICE_CODE` generated by the burner. Register that code with the matching Device ID in the signed-in dashboard; cloud stores only its SHA-256 hash. Device endpoints require HTTPS. The captive portal is limited to Wi-Fi credentials. User API keys remain available for external telemetry and firmware integrations but are not used by the ESP32 firmware.

Firmware releases are published from the dashboard with one target per release: `servo` for COM6 or `ga25` for COM8.
