CENTRO DE DESARROLLO

Wiki & API.

Todo lo que necesitas para conectar un nuevo ESP32 a Pulsegrid.

Primeros pasosReferencia API
API REST + MQTT

Conecta tu hardware en minutos

Usa nuestra API para registrar dispositivos, enviar telemetria y escuchar comandos.

01

Registra tu dispositivo

Crea un dispositivo desde el panel y guarda el device_id y device_token. Nunca expongas tu token en el frontend.

esp32_setup.ino
const char* DEVICE_ID = "esp32-01";
const char* DEVICE_TOKEN = "pg_live_xxxxxxxxx";

void setup() {
  Serial.begin(115200);
  pulsegrid.begin(DEVICE_ID, DEVICE_TOKEN);
}
02

Reporta telemetria

Publica lecturas con una frecuencia definida por tu dispositivo. El dashboard actualiza los valores en tiempo real.

POST/v1/devices/{device_id}/telemetry
03

Escucha comandos

Suscribete al topic MQTT del dispositivo para ejecutar acciones enviadas desde el centro de comandos.

MQTTdevices/{device_id}/commands
